## 📱 О ПРОЕКТЕ

**SOS UNIVERSAL** — это прогрессивное веб-приложение (PWA), которое помогает в любых жизненных ситуациях. Оно работает **полностью офлайн** и содержит 9 модулей помощи:

| Модуль | Эмодзи | Описание | Статус |
|--------|--------|----------|--------|
| **Выживание** | 🆘 | Вода, огонь, еда, укрытие, медицина, навигация | ✅ Готов |
| **Авто** | 🚗 | Поломки, ДТП, шины, аккумулятор, тормоза | ✅ Готов |
| **Юрист** | ⚖️ | ДТП, жильё, наследство, развод, долги | ✅ Готов |
| **Дом** | 🏠 | Пожар, газ, электричество, сантехника, замки | ✅ Готов |
| **Дети** | 👶 | Безопасность, буллинг, здоровье, потеря | ✅ Готов |
| **Животные** | 🐕 | Первая помощь, потеря, отравление, здоровье | ✅ Готов |
| **Путешествия** | ✈️ | Документы, кража, здоровье, отели, рейсы | ✅ Готов |
| **Дроны** | 🪖 | Инструкции, связь, эвакуация, первая помощь | ✅ Готов |
| **Энергия** | ⚡ | Зарядка, батарейки, солнечная энергия, динамо | ✅ Готов |

## 🚀 КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ

### 🎯 Интерактивные квизы
Ответьте на 3–5 вопросов — получите пошаговые решения с инструкциями и предупреждениями.

### 🌍 Мультиязычность
- 🇷🇺 Русский
- 🇬🇧 English

Переключайте язык в один клик.

### 🌓 Тёмная / Светлая тема
Комфортное использование в любых условиях — днём и ночью.

### 📴 Полностью офлайн
Все данные и логика работают без интернета. Установите приложение на телефон — и оно всегда с вами.

### 🎤 Голосовое управление
Скажите:
- "Авто" — перейти в модуль
- "ДТП" — запустить категорию
- "Назад" — вернуться
- "SOS" — экстренная помощь

### 🆘 SOS-режим
- Отправка SMS с координатами близким
- Сигналы бедствия (3 огня, зеркало, свисток)
- Фонарик с SOS-миганием
- Психология выживания

## 📦 УСТАНОВКА И ЗАПУСК

### 1. Клонирование

```bash
git clone https://github.com/zimatoken/sos-universal.git
cd sos-universal
2. Локальный запуск
bash
# Python
python -m http.server 8000

# Node.js
npx serve

# VS Code (Live Server)
# Нажми правой кнопкой на index.html → Open with Live Server
3. Установка PWA
Android: Откройте приложение в Chrome → "Добавить на главный экран"

iOS: Откройте в Safari → "Поделиться" → "На экран «Домой»"
