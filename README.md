# SOS UNIVERSAL

Супер-приложение для любых ситуаций.

## Структура проекта

```
sos-universal/
├── index.html              # Главный экран с 8 модулями
├── manifest.json           # PWA манифест
├── 404.html                # Страница 404
├── core/                   # Основные файлы
│   ├── locales.js          # Общие локализации
│   ├── theme.js            # Переключатель темы
│   ├── engine.js           # Движок фильтрации решений
│   └── app.js              # Логика приложения
├── css/                    # Стили
│   ├── styles.css          # Основные стили
│   └── modules/            # Стили модулей
│       └── survival.css    # Стили модуля выживания
├── modules/                # Модули
│   └── survival/           # Модуль выживания
│       ├── index.html      # Экран квиза выживания
│       ├── icon.svg        # Иконка модуля
│       ├── i18n.js         # Локализации модуля
│       └── data/           # Данные категорий
│           ├── index.js    # Экспорт данных
│           ├── water.js    # Категория: Вода
│           ├── fire.js     # Категория: Огонь
│           ├── shelter.js  # Категория: Укрытие
│           ├── food.js     # Категория: Еда
│           ├── medicine.js # Категория: Медицина
│           ├── navigation.js # Категория: Навигация
│           ├── radio.js    # Категория: Связь
│           ├── kit.js      # Категория: Чемоданчик
│           └── *-en.js     # Английские версии
└── assets/                 # Ресурсы
    └── icons/              # Иконки PWA
        ├── icon-192.png
        └── icon-512.png
```

## Запуск

Просто откройте `index.html` в браузере или запустите локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

## Разработка

### Добавление нового модуля

1. Создайте папку `modules/[module-name]/`
2. Создайте `index.html` с интерфейсом модуля
3. Создайте `i18n.js` с локализациями
4. Создайте `icon.svg` с иконкой
5. Добавьте данные в `data/` если нужно
6. Создайте `css/modules/[module-name].css`
7. Добавьте кнопку модуля в главный `index.html`

### Структура модуля

Модуль должен:
- Иметь кнопку "← Назад" для возврата на главный экран
- Использовать `../../core/` для подключения основных файлов
- Иметь свои локализации в `i18n.js`
- Иметь свои стили в `css/modules/[module].css`
